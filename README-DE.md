## 🔄 Git Workflow

### Setup: Zwei Remotes

```bash
origin   → bastiantonn/everything-claude-code (PRIVATE)
upstream → affaan-m/everything-claude-code (PUBLIC)
```

### Eigene Änderungen

```bash
git add .
git commit -m "feat: Meine Anpassung"
git push origin main
```

### Updates vom Original

```bash
git fetch upstream
git merge upstream/main
git push origin main
```

**Mehr Details:** [WORKFLOW-PRIVATE-FORK.md](./WORKFLOW-PRIVATE-FORK.md)
